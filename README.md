# MIMIC - EDA Branch

Exploratory data analysis for word embeddings.

## Purpose

Initial exploration of embedding spaces to inform agent design decisions for the main MIMIC framework.

## Contents

- Loading and caching word vectors
- Similarity search and distance metrics
- Visualization of semantic neighborhoods
- Analysis of word clustering patterns

## Usage

```bash
pip install -r requirements.txt
python glove_loader.py
```

## Notes

This branch is for experimentation only. Findings will be integrated into the main agent framework.
